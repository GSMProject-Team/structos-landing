Расчёт → армирование в Revit → чертежи, без ручного переноса между программами

StructOS напрямую связывает ЛИРА-САПР, Tekla Structures, Revit, AutoCAD и IDEA StatiCa: читает усилия и подобранные сечения из расчёта, строит геометрию и оформляет КЖ/КМ-чертежи — без экспорта в промежуточные форматы и без ручного дублирования данных.

Что покрывает StructOS

Не одна интеграция, а связующий слой между программами, которые проектное бюро уже использует.

ЛИРА-САПР расчёт

Усилия, РСУ/РСН, подбор сечений и армирования, устойчивость, сейсмика — чтение прямо из модели, без выгрузки в текст.

Tekla Structures КМ/КМД

Геометрия, узлы, профилировка через Open API; спецификации, развёртки, нумерация, экспорт NC.

Revit КЖ

Армирование, штампы по ГОСТ 21.101, листы, семейства, экспорт IFC.

AutoCAD чертежи

Чтение и построение чертежей, оси, блоки, сопоставление со сметой и КМ.

IDEA StatiCa узлы

Проверка узловых соединений (CBFEM) по усилиям из расчёта.

Нормативы по странам

СП РК (Казахстан), ГОСТ (СНГ), Eurocode (ЕС) — норматив всегда с указанием страны, потому что требования у каждой страны свои.

Пример конвейера: ЛИРА → Tekla

Самый частый цикл в металлоконструкциях — от расчёта до готового комплекта КМ.

1

Расчёт в ЛИРА

Усилия, РСУ, подбор армирования и сечений читаются напрямую из модели.

2

Сопоставление

Марки элементов ЛИРА связываются с объектами Tekla — балки, колонны, плиты.

3

Построение в Tekla

Геометрия, профили и армирование создаются через Open API, in-process.

4

КМ-чертежи

Спецификации, развёртки, оформление по стандарту — на выходе готовый комплект КМ.

Как это устроено

StructOS.exe работает полностью на компьютере клиента. За пределы уходит только по четырём условным каналам — пятого пути нет.

полностью локально пересекает границу — условно
01 · Баг-репорт

structos_report_bug

Собирает ошибку из локального лога, маскирует пути/email/ключи.

confirm=True + человек жмёт Submit
02 · Запрос функции

structos_request_feature

Готовит GitHub Issue из "мне нужна программа X".

confirm=True + человек жмёт Submit
03 · Contribution

contrib.flush()

Только цифры: какой инструмент сколько раз ошибся, какой профиль не распознан. Ни кода, ни модели.

разовое согласие заранее, по умолчанию выключено
04 · Update-check

update_check

Спрашивает только "есть ли новая версия". Установка — отдельный, проверенный шаг.

один запрос в день, без данных клиента

Почему именно так: протокол MCP вообще не передаёт серверу историю переписки — StructOS не может прочитать диалог, даже если бы захотел. А каждый из четырёх каналов сначала показывает человеку, что будет отправлено, и только потом, с явного разрешения, пересекает границу.

Кому подходит

Подходит

  • Бесплатно на время беты, лицензионный ключ не нужен
  • Без облачной загрузки моделей — всё считается локально

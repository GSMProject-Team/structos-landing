Инженерная автоматизация

ЛИРА-САПР → Tekla Structures без ручного переноса

StructOS читает результаты расчёта и подобранное армирование прямо из ЛИРА, строит геометрию и КМ-чертежи в Tekla через Open API — без экспорта в промежуточные форматы и без ручного ввода сечений.

Запросить демо Как это работает

Конвейер ЛИРА → Tekla

1

Расчёт в ЛИРА

Усилия, РСУ, подбор армирования и сечений читаются напрямую из модели.

2

Сопоставление

Марки элементов ЛИРА связываются с объектами Tekla — балки, колонны, плиты.

3

Построение в Tekla

Геометрия, профили и армирование создаются через Open API, in-process.

4

КМ-чертежи

Спецификации, развёртки, оформление по стандарту — на выходе готовый комплект КМ.

Кому подходит

Подходит

  • Проектные бюро, которые считают в ЛИРА и оформляют в Tekla
  • Металлоконструкции с повторяющимся циклом расчёт → КМ
  • Команды, где перенос сечений и армирования вручную — узкое место

Как поставляется

  • Локальный MCP-сервер (pip install) — работает на машине инженера, рядом с ЛИРА и Tekla
  • Годовой B2B-договор с проектным бюро, оплата по счёту
  • Без облачной загрузки моделей — всё считается локально

Демо-доступ

Покажем конвейер на вашей модели. Договор и счёт — после демо, без каких-либо предоплат картой.
